> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Fixpoint web frontend (landing, chat, evals) in `frontend/`. It works today against an in-repo mock API, and against the real FastAPI backend once `NEXT_PUBLIC_API_URL` is set.

**Architecture:** Next.js 16 App Router with client components for everything interactive.
- All backend I/O goes through `lib/api.ts`: fetch, plus a hand-written SSE parser for `POST /ask`.
- The pure state and formatting logic sits in small `lib/*.ts` modules with Node built-in tests.
- When `NEXT_PUBLIC_API_URL` is unset, `lib/api.ts` points at `/api/mock`. That folder holds Next route handlers that stream real SSE and keep eval-run state in memory.
- The visual language copies Café De (`~/Desktop/RazorPay/cafe-de-agent/apps/web`) with a teal tint. shadcn/ui's CSS variables are mapped onto those tokens.

**Tech Stack:** Next.js 16.4.2 (cacheComponents on, Turbopack), React 19.3, TypeScript 5.9, Tailwind 4, shadcn 4.21.5 (`base-nova` style on Base UI), Recharts 3 (via the shadcn chart component), lucide-react, pnpm 10, Node 25 (`node --test` with native type stripping).

**Spec:** `docs/superpowers/specs/2026-10-16-frontend-design.md`. Parent PRD: GitHub issue #1.

## Review Focus

The spec implies these inputs, and they are the ones most likely to bite real users. Each has a test in the task that owns the code.

1. **A stream ends without an `answer` event** (Render restarts, a proxy timeout, a dropped connection). The turn must show "the connection closed" with Try again, never spin forever. Owned by Task 2 (`api.test.ts`), plus the `mock drop` trigger in Task 9.
2. **An error response isn't JSON** (Render's HTML 502 during a cold start, or a 429 with only a `Retry-After` header). The user gets a readable sentence, never raw HTML. Owned by Task 2 (`api.test.ts`).
3. **A new question while one is running, or late events from an aborted stream.** The old turn reads "Stopped", and its late events are ignored. Owned by Task 3 (`turns.test.ts`).
4. **Cell values the backend really sends:** Postgres numerics as strings (`"4.45"`), `null`, midnight timestamps, leading-zero codes, year columns. Table and chart must stay consistent. Owned by Task 3 (`format.test.ts`).
5. **localStorage unavailable or throwing** (Safari private mode, blocked site data). The theme toggle and admin token must keep working without persistence. Owned by Task 3 (`storage.test.ts`).

```ts
/**
 * Yields the data payload of each server-sent event in a stream of text chunks.
 * Events end at a blank line; lines end in \n, \r\n or \r (sse-starlette sends \r\n); multi-line data joins
 * with \n; comments and other fields are ignored; an unterminated last event is dropped, as the SSE spec says.
 */
export async function* sseData(chunks: AsyncIterable<string>): AsyncGenerator<string> {
  let buffer = "";
  for await (const chunk of chunks) {
    buffer += chunk;
    // Hold back a trailing \r: it may be the first half of a \r\n split across chunks.
    const held = buffer.endsWith("\r") ? "\r" : "";
    const blocks = buffer
      .slice(0, buffer.length - held.length)
      .replace(/\r\n?/g, "\n")
      .split("\n\n");
    buffer = (blocks.pop() ?? "") + held;
    for (const block of blocks) {
      const data = block
        .split("\n")
        .filter((line) => line.startsWith("data:"))
        .map((line) => line.slice(line.startsWith("data: ") ? 6 : 5));
      if (data.length) yield data.join("\n");
    }
  }
}
```

```ts
import { sseData } from "./sse.ts";
import type { AskEvent, EvalRun, RunDetail, Split } from "./types.ts";

/** The Fixpoint API. Unset means the in-repo mock under app/api/mock, so the UI runs without a backend. */
export const API_URL = process.env.NEXT_PUBLIC_API_URL || "/api/mock";
export const IS_MOCK = API_URL === "/api/mock";
export const ADMIN_HEADER = "X-Admin-Token";

export class ApiError extends Error {
  status: number;
  retryAfterS: number | null;

  constructor(message: string, status: number, retryAfterS: number | null = null) {
    super(message);
    this.name = "ApiError";
    this.status = status;
    this.retryAfterS = retryAfterS;
  }
}

function headers(token: string | null | undefined, json: boolean): Record<string, string> {
  const h: Record<string, string> = {};
  if (json) h["Content-Type"] = "application/json";
  if (token) h[ADMIN_HEADER] = token;
  return h;
}

export function formatWait(seconds: number): string {
  if (seconds < 60) return `${Math.ceil(seconds)} s`;
  if (seconds < 3600) return `${Math.ceil(seconds / 60)} min`;
  return `${Math.ceil(seconds / 3600)} h`;
}

/** Turns a failed response into one readable sentence, whatever the body is. */
async function failure(res: Response): Promise<ApiError> {
  let detail = "";
  let retry: number | null = null;
  try {
    const body = (await res.json()) as { detail?: unknown; retry_after_s?: unknown } | null;
    if (typeof body?.detail === "string") detail = body.detail;
    if (typeof body?.retry_after_s === "number") retry = body.retry_after_s;
  } catch {
    // Not JSON: a proxy's HTML error page, or an empty body.
  }
  const header = Number(res.headers.get("Retry-After"));
  if (retry === null && header > 0) retry = header;
  if (res.status === 429) {
    const wait = retry ? `in ${formatWait(retry)}` : "a bit later";
    return new ApiError(`You've reached the question limit. Try again ${wait}.`, 429, retry);
  }
  if (res.status === 401 || res.status === 403) return new ApiError("The admin token was rejected.", res.status);
  if (res.status >= 500) {
    return new ApiError("The server is unavailable. It may be waking up; try again in a minute.", res.status);
  }
  return new ApiError(detail || `Request failed (${res.status}).`, res.status);
}

async function* textChunks(body: ReadableStream<Uint8Array>): AsyncGenerator<string> {
  const reader = body.pipeThrough(new TextDecoderStream()).getReader();
  try {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) return;
      yield value;
    }
  } finally {
    reader.releaseLock();
  }
}

/**
 * Asks a question and yields the agent's step events, then one answer (or one error) event.
 * Aborting `signal` closes the connection, which cancels the run on the server.
 */
export async function* ask(
  question: string,
  opts: { signal?: AbortSignal; token?: string | null; fetchImpl?: typeof fetch } = {},
): AsyncGenerator<AskEvent> {
  const res = await (opts.fetchImpl ?? fetch)(`${API_URL}/ask`, {
    method: "POST",
    headers: { ...headers(opts.token, true), Accept: "text/event-stream" },
    body: JSON.stringify({ question }),
    signal: opts.signal,
  });
  if (!res.ok || !res.body) throw await failure(res);
  for await (const data of sseData(textChunks(res.body))) {
    const event = JSON.parse(data) as AskEvent;
    yield event;
    if (event.type !== "step") return;
  }
  throw new ApiError("The connection closed before an answer arrived.", 0);
}

async function json<T>(path: string, init: RequestInit = {}, token?: string | null): Promise<T> {
  const res = await fetch(`${API_URL}${path}`, {
    ...init,
    headers: headers(token, init.body !== undefined),
    cache: "no-store",
  });
  if (!res.ok) throw await failure(res);
  return (await res.json()) as T;
}

export const listRuns = () => json<EvalRun[]>("/evals/runs");
```

```ts
import type { Answer, AskEvent, StepEvent } from "./types.ts";

export type TurnStatus = "running" | "done" | "error" | "cancelled";

export interface Turn {
  id: number;
  question: string;
  steps: StepEvent[];
  answer: Answer | null;
  status: TurnStatus;
  error: string | null;
}

export type TurnAction =
  | { type: "start"; id: number; question: string }
  | { type: "event"; id: number; event: AskEvent }
  | { type: "fail"; id: number; message: string }
  | { type: "cancel"; id: number };

/**
 * Chat state. One turn runs at a time: starting a new one stops any still running, and a stopped or
 * finished turn ignores whatever its old stream still delivers.
 */
export function turnsReducer(turns: Turn[], action: TurnAction): Turn[] {
  if (action.type === "start") {
    const settled = turns.map((t): Turn => (t.status === "running" ? { ...t, status: "cancelled" } : t));
    return [
      ...settled,
      { id: action.id, question: action.question, steps: [], answer: null, status: "running", error: null },
    ];
  }
  return turns.map((t) => (t.id === action.id && t.status === "running" ? apply(t, action) : t));
}

function apply(t: Turn, action: Exclude<TurnAction, { type: "start" }>): Turn {
  switch (action.type) {
    case "cancel":
      return { ...t, status: "cancelled" };
    case "fail":
      return { ...t, status: "error", error: action.message };
    case "event": {
      const e = action.event;
      if (e.type === "step") return { ...t, steps: [...t.steps, e] };
      if (e.type === "answer") return { ...t, answer: e, status: "done" };
      return { ...t, status: "error", error: e.message };
    }
  }
}
```

```ts
import type { Cell } from "./types.ts";

const NUMERIC = /^-?\d+(?:\.\d+)?(?:e[+-]?\d+)?$/i;
const MIDNIGHT = /^(\d{4}-\d{2}-\d{2})[T ]00:00:00(?:\.0+)?(?:Z|[+-]00(?::?00)?)?$/;
const UNGROUPED = /(^|_)(year|yr|id)$/i;

/** Numbers and numeric strings (Postgres numerics arrive as strings) as numbers; anything else null. */
export function toNumber(v: Cell): number | null {
  if (typeof v === "number") return Number.isFinite(v) ? v : null;
  if (typeof v === "string" && NUMERIC.test(v)) return Number(v);
  return null;
}

/** A result cell as text. Leading-zero codes stay strings; years and ids get no thousands separators. */
export function formatCell(v: Cell, column = ""): string {
  if (v === null) return "null";
  if (typeof v === "boolean") return String(v);
  const n = toNumber(v);
  const code = typeof v === "string" && /^-?0\d/.test(v);
  if (n !== null && !code) {
    return n.toLocaleString("en-US", { maximumFractionDigits: 2, useGrouping: !UNGROUPED.test(column) });
  }
  if (typeof v === "string") return MIDNIGHT.exec(v)?.[1] ?? v;
  return String(v);
}
```

```ts
import type { EvalResult, EvalRun } from "./types.ts";

const newestFirst = (runs: EvalRun[]) =>
  runs.filter((r) => r.status === "done").sort((a, b) => b.started_at.localeCompare(a.started_at));

/** The newest finished memory-on and memory-off runs on the same split, taking the split with the newest such pair. */
export function pickComparison(runs: EvalRun[]): { on: EvalRun; off: EvalRun } | null {
  const done = newestFirst(runs);
  for (const r of done) {
    const other = done.find((o) => o.split === r.split && o.memory !== r.memory);
    if (other) return r.memory ? { on: r, off: other } : { on: other, off: r };
  }
  return null;
}

/** The run the landing page quotes: the newest finished test-split run, else the newest finished run. */
export function latestDone(runs: EvalRun[]): EvalRun | null {
  const done = newestFirst(runs);
  return done.find((r) => r.split === "test") ?? done[0] ?? null;
}

export const anyRunning = (runs: EvalRun[]) => runs.some((r) => r.status === "running");

/** Failure modes worth a badge: verified but wrong, and right on the first try but wrong after repair. */
export function flags(r: EvalResult): { confidentlyWrong: boolean; regression: boolean } {
  return {
    confidentlyWrong: r.kind === "answerable" && r.verified && !r.final_correct,
    regression: r.first_try_correct && !r.final_correct,
  };
}
```

```ts
    const o = memory ? q.on : q.off;
    const predicted = o.predicted_kind ?? "answerable";
    const classified = q.kind !== "answerable";
    const tries = Math.max(o.attempts, 1);
    return {
      question_id: q.id,
      question: q.question,
      kind: q.kind,
      predicted_kind: predicted,
      first_try_correct: classified ? predicted === q.kind : o.first_try_correct,
      final_correct: classified ? predicted === q.kind : o.final_correct,
      verified: o.verified,
      attempts: o.attempts,
      cost_usd: Number((0.0012 + 0.0011 * tries + (i % 5) * 0.0003).toFixed(4)),
      latency_ms: 6000 + tries * 9000 + ((i * 7919) % 9000),
      gold_sql: q.gold,
      agent_sql: classified ? "" : o.final_correct ? q.gold : (q.wrong ?? q.gold),
      trace_url: `https://cloud.langfuse.com/project/mock/traces/${memory ? "on" : "off"}-${q.id}`,
    };
  });
}

type Metrics = Omit<EvalRun, "id" | "status" | "started_at" | "finished_at" | "git_sha" | "model" | "split" | "memory">;

const NO_METRICS: Metrics = {
  n: 0, n_answerable: 0, n_ambiguous: 0, n_unanswerable: 0, first_try_acc: null, final_acc: null,
  repair_uplift: null, repair_regressions: null, confidently_wrong: null, clarification_f1: null,
  refusal_acc: null, cost_per_correct: null, p50_ms: null, p95_ms: null,
};

function summarize(rs: EvalResult[]): Metrics {
  const ans = rs.filter((r) => r.kind === "answerable");
  const amb = rs.filter((r) => r.kind === "ambiguous");
  const una = rs.filter((r) => r.kind === "unanswerable");
  const share = (xs: EvalResult[], f: (r: EvalResult) => boolean) => (xs.length ? xs.filter(f).length / xs.length : null);
  const first = share(ans, (r) => r.first_try_correct);
  const final = share(ans, (r) => r.final_correct);
  const tp = amb.filter((r) => r.predicted_kind === "ambiguous").length;
  const predicted = rs.filter((r) => r.predicted_kind === "ambiguous").length;
  const precision = predicted ? tp / predicted : 0;
  const recall = amb.length ? tp / amb.length : 0;
  const correct = ans.filter((r) => r.final_correct).length;
  const latency = rs.map((r) => r.latency_ms).sort((a, b) => a - b);
  const quantile = (p: number) => latency[Math.min(latency.length - 1, Math.floor(p * latency.length))];
  return {
    n: rs.length,
    n_answerable: ans.length,
    n_ambiguous: amb.length,
    n_unanswerable: una.length,
    first_try_acc: first,
    final_acc: final,
    repair_uplift: first === null || final === null ? null : final - first,
    repair_regressions: ans.filter((r) => r.first_try_correct && !r.final_correct).length,
    confidently_wrong: ans.filter((r) => r.verified && !r.final_correct).length,
    clarification_f1: precision + recall ? (2 * precision * recall) / (precision + recall) : 0,
    refusal_acc: share(una, (r) => r.predicted_kind === "unanswerable"),
    cost_per_correct: correct ? rs.reduce((s, r) => s + r.cost_usd, 0) / correct : null,
    p50_ms: quantile(0.5),
    p95_ms: quantile(0.95),
  };
}

interface Stored {
  run: EvalRun;
  results: EvalResult[];
  finishesAt?: number;
}

interface Store {
  runs: Stored[];
}

const BASE = { git_sha: "508bdb2", model: "gemini-3.8-flash" };

function seed(): Store {
  const interrupted = results(true).slice(0, 6);
  return {
    runs: [

        results: results(false),

// On globalThis so every route module (and dev hot reloads) shares one store.
const g = globalThis as typeof globalThis & { __fixpointMockEvals?: Store };
const store = () => (g.__fixpointMockEvals ??= seed());

/** A started run finishes 15 s later, the next time anyone reads it. */
function settle(s: Stored): void {
  if (s.run.status !== "running" || !s.finishesAt || Date.now() < s.finishesAt) return;
  s.results = results(s.run.memory);
  s.run = { ...s.run, status: "done", finished_at: new Date().toISOString(), ...summarize(s.results) };
}

export function listRuns(): EvalRun[] {
  const { runs } = store();
  runs.forEach(settle);
  return runs.map((s) => s.run).reverse();
}

export function getRun(id: number): RunDetail | null {
  const s = store().runs.find((r) => r.run.id === id);
  if (!s) return null;
  settle(s);
  return { run: s.run, results: s.results };
}

/** Starts a run, or returns null when one is already running (the API answers 409). */
export function startRun(split: Split, memory: boolean): { id: number } | null {
  const { runs } = store();
  runs.forEach(settle);
  if (runs.some((s) => s.run.status === "running")) return null;
  const id = Math.max(...runs.map((s) => s.run.id)) + 1;
  runs.push({
    run: { id, status: "running", started_at: new Date().toISOString(), finished_at: null, split, memory, ...BASE, ...NO_METRICS },
    results: [],
    finishesAt: Date.now() + 15_000,
  });
  return { id };
}
```

```ts
function pause(ms: number, signal: AbortSignal): Promise<void> {
  return new Promise((resolve) => {
    const timer = setTimeout(resolve, ms);

export async function POST(request: Request) {
  const body = (await request.json().catch(() => ({}))) as { question?: unknown };
  const question = typeof body.question === "string" ? body.question.trim() : "";
  if (!question || question.length > 500) {
    return Response.json({ detail: "The question must be 1 to 500 characters." }, { status: 422 });
  }
  const script = scenarioFor(question);
  if (script.kind === "status") return Response.json(script.body, { status: script.status });

  const { signal } = request;
  const stream = new ReadableStream<Uint8Array>({
    async start(controller) {
      for (const event of script.events) {
        // Model calls take seconds; a short pause per step keeps the timeline readable without dragging.
        await pause(event.type === "step" ? 300 + Math.random() * 500 : 400, signal);
        if (signal.aborted) break;
        controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\r\n\r\n`));
      }
      try {
        controller.close();
      } catch {
        // Already closed by the client going away.
      }
    },
  });
  return new Response(stream, {
    headers: { "Content-Type": "text/event-stream", "Cache-Control": "no-cache, no-transform" },
  });
}
```

```tsx
import type { StepEvent } from "@/lib/types";

const LABEL: Record<StepEvent["node"], string> = {
  planner: "Plan",
  coder: "Write SQL",
  executor: "Run",
  verifier: "Check",
  debugger: "Repair",
  explainer: "Explain",
};

type Kind = "ok" | "fail" | "repair" | "replan";

// "Failed" and "Gave up: ..." are the summaries the agent's fail() and explainer() emit (backend/src/fixpoint/agent.py).
function kindOf(step: StepEvent, index: number): Kind {
  if (step.summary === "Failed" || step.summary.startsWith("Gave up")) return "fail";
  if (step.node === "debugger") return "repair";
  if (step.node === "planner" && index > 0) return "replan";
  return "ok";
}

function summaryOf(step: StepEvent): string {
  if (step.summary === "Failed") return step.detail.split("\n")[0];
  return step.summary.replace(/^(Plan|Repair): /, "").replace(/^1 rows$/, "1 row");
}

const ICON: Record<Kind, React.ReactNode> = {
  ok: <Check className="size-4 text-primary" />,
  fail: <X className="size-4 text-danger-foreground" />,
  repair: <Wrench className="size-4 text-warning-foreground" />,
  replan: <RefreshCw className="size-4 text-warning-foreground" />,
};

export function StepTimeline({ steps, running }: { steps: StepEvent[]; running: boolean }) {
  if (!steps.length && !running) return null;
  return (
    <ol className="flex flex-col gap-1" aria-label="Agent steps" aria-live="polite">
      {steps.map((s, i) => {
        const kind = kindOf(s, i);
        const attemptStarts = s.attempt > 1 && s.attempt !== steps[i - 1]?.attempt;

        return (
```

```tsx
"use client";

import { ArrowUp } from "lucide-react";
import { useSearchParams } from "next/navigation";
import { useCallback, useEffect, useReducer, useRef, useState } from "react";
import { ExampleQuestions } from "@/components/chat/example-questions";
import { TurnView } from "@/components/chat/turn-view";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { useAdminToken } from "@/lib/admin";
import { ApiError, ask } from "@/lib/api";
import { turnsReducer } from "@/lib/turns";

const MAX_QUESTION = 500;

export function Chat() {
  const [turns, dispatch] = useReducer(turnsReducer, []);
  const [draft, setDraft] = useState("");
  const [token] = useAdminToken();
  const controller = useRef<AbortController | null>(null);
  const nextId = useRef(1);
  const pendingAbort = useRef<ReturnType<typeof setTimeout> | undefined>(undefined);
  const params = useSearchParams();
  const linked = useRef(false);

  const run = useCallback(
    async (question: string) => {
      const q = question.trim().slice(0, MAX_QUESTION);
      if (!q) return;
      controller.current?.abort();
      const c = new AbortController();
      controller.current = c;
      const id = nextId.current++;
      dispatch({ type: "start", id, question: q });
      requestAnimationFrame(() =>
        document.getElementById(`turn-${id}`)?.scrollIntoView({ behavior: "smooth", block: "start" }),
      );
      try {
        for await (const event of ask(q, { signal: c.signal, token })) dispatch({ type: "event", id, event });
      } catch (e) {
        if (c.signal.aborted) dispatch({ type: "cancel", id });
        else
          dispatch({
            type: "fail",
            id,
            message: e instanceof ApiError ? e.message : "Couldn't reach the server. Check your connection and try again.",
          });
      }
    },
    [token],
  );

  // /ask?q=... asks on arrival, so a question can be linked to.
  useEffect(() => {
    const q = params.get("q");
    if (q && !linked.current) {
      linked.current = true;
      void run(q);
    }
  }, [params, run]);

  // Leaving the page (or Next hiding it during navigation) aborts the stream, which cancels the run on the server.
  // Deferred a tick so React's dev StrictMode unmount-and-remount doesn't kill a run that was just started.
  useEffect(() => {
    clearTimeout(pendingAbort.current);
    return () => {
      pendingAbort.current = setTimeout(() => controller.current?.abort(), 0);
    };
  }, []);

  return (
    <div className="flex min-h-[calc(100dvh-7.5rem)] flex-col">
      {turns.length === 0 ? (
        <section className="py-4">
          <p className="eyebrow">Ask the warehouse</p>
          <h1 className="mt-2">What do you want to know?</h1>
          <p className="mt-2 max-w-[62ch] text-muted-foreground">
            Ask about orders, customers, sellers, payments, reviews and delivery in the Olist marketplace, September
            2016 to October 2018. Every answer shows its SQL, and a result that fails a check is repaired before you see
            it.
          </p>
          <ExampleQuestions onPick={run} />
        </section>
      ) : (
        <ol className="flex flex-col gap-10 pb-6">
          {turns.map((t) => (
            <li key={t.id} id={`turn-${t.id}`} className="scroll-mt-20">
              <TurnView turn={t} onAsk={run} />
            </li>
          ))}
        </ol>
      )}
      <form
        className="sticky bottom-0 mt-auto -mx-4 border-t bg-background/95 px-4 py-3 backdrop-blur sm:-mx-6 sm:px-6"
        onSubmit={(e) => {
          e.preventDefault();
          void run(draft);
          setDraft("");
        }}
      >
        <div className="flex gap-2">
          <Input
            value={draft}
            onChange={(e) => setDraft(e.target.value)}
            maxLength={MAX_QUESTION}
            placeholder="Ask a question about the marketplace"
            aria-label="Your question"
            className="h-10 bg-card"
          />

            <ArrowUp data-icon="inline-start" />
            <span className="max-sm:sr-only">Ask</span>
          </Button>
        </div>
        {draft.length > MAX_QUESTION - 100 && (
          <p className="mt-1 text-right text-xs text-muted-foreground tabular">
            {draft.length}/{MAX_QUESTION}
          </p>
        )}
      </form>
    </div>
  );
}
```

```ts
"use client";

import { useEffect } from "react";

/** Calls `load` now and whenever it changes, then every `ms` while `active` (a run is in progress). */
export function usePolling(load: () => Promise<unknown>, active: boolean, ms = 5000): void {
  useEffect(() => {
    void load();
  }, [load]);
  useEffect(() => {
    if (!active) return;
    const timer = setInterval(() => void load(), ms);
    return () => clearInterval(timer);
  }, [load, active, ms]);
}
```
